# 정산 후 첫 입장 결과 안내

## 동작
- 웹/앱인토스 및 SwiftUI iOS에서 미확인 정산 결과를 첫 입장과 앱 복귀 시 조회한다.
- 경기별 적중/실패, 내 예측, 실제 스코어, 지수 증감, 획득 포인트와 합계를 표시한다. 지수와 포인트는 구분한다.
- 명시적인 확인 버튼으로 표시된 결과만 계정 단위 확인 처리한다. 단순 조회는 확인 처리하지 않는다.
- 웹과 iOS는 같은 계정의 확인 기록을 공유한다. 기존 미확인 정산도 포함하며 한 번에 최대 100개를 표시한다.
- 저장 실패 시 안내를 유지하고 재시도한다. 새로 정산된 결과가 이전 화면 확인에 섞여 사라지지 않는다.
- 정산 점수 자체를 변경하거나 재지급하지 않는다.
