# 국제대회·국가대표 경기 지원

- 원인: 수집기가 EPL/라리가/분데스리가/세리에A 4개 ID에 고정돼 있었고, 기존 회원의 league_order에 신규 대회가 자동 추가되지 않았다.
- API-Football `/leagues?country=World` 카탈로그에 속한 11인제 국제대회와 기존 4개 리그를 날짜별 `/fixtures?date=`로 수집한다. 비표준 7인제 Kings World Cup Nations(1213)는 제외한다.
- UEFA 챔피언스·유로파·컨퍼런스, 국가대표 친선, 월드컵/대륙별 예선, 네이션스리그, 여자·연령별 국제대회와 국제 클럽대회를 포함한다. 주요 대회 외에는 실제 일정이 있을 때 카탈로그에 추가한다. 세부 통계가 없는 대회의 통계를 만들어 넣지 않는다.
- 매일 04:00 KST, 과거 3일~향후 60일의 날짜 64개 및 대회 카탈로그 1회 = 일정 수집 65호출/일. Pro 7,500호출/일 확인.
- `team_competitions` 복수 소속 도입. 기존 팀 대표 리그, 한글명, 색, 기존 약어 보존. 신규 경기의 팀을 먼저 저장해 FK 누락 방지.
- 대회 선택 메뉴와 주요 대회 가로 탭. 기존 사용자 선호 순서를 유지하며 새 대회도 표시한다. 토너먼트 라운드 원문 보존, 국내 리그 순위를 국제대회 순위로 잘못 표시하지 않는다.
- 팀·경기 조회 페이지네이션으로 PostgREST 1,000행 제한에 따른 누락 방지.
- 국제대회 조별 순위표/별도 전력 모델은 이 변경에 포함하지 않는다. 기존 결과·라이브·라인업·배당·상대전적 수집은 경기 ID 기준으로 동작한다.
