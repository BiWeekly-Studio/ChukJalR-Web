# 2026-09-07 기능 동기화 및 배포

## 반영
- 웹: 프로필 이름/사진 편집, 예측 기록 최근 100건, 예측 지수 추이, 계정 삭제, 랭킹/채팅 프로필 사진.
- iOS 빌드 5: 서버 기준 확률과 참여자 수 조회, 웹과 동일한 일정 조회 기간.
- 토스: 로그인 서버 인증서/키 등록, 숫자 userKey 처리, 연결 해제 콜백과 서버 계정 삭제, 서울 리전 지정.
- 웹과 iOS는 같은 Supabase 데이터/점수 규칙을 사용. 같은 로그인 계정으로 접근해야 기록이 공유됨. 토스 계정은 별도이며 자동 병합하지 않음.

## 검증
- npm test: 14개 통과.
- 웹 및 토스 프로덕션 빌드 성공. iOS 시뮬레이터 빌드와 배포 아카이브 성공.
- scripts/verify-ios-baselines.sh: 서버 기준 확률/참여자 수와 누락/잘못된 값 처리 통과.
- scripts/verify-profile-sync.mjs: 임시 계정으로 이름 변경/7일 제한, 사진 저장/조회/제거, 기록 조회, 탈퇴와 세션 해제 통과. 임시 계정 정리됨.
- 토스 연결 해제 엔드포인트: OPTIONS 204, 잘못된 인증 401, 유효 인증+존재하지 않는 테스트 키 200, 서울 리전 확인. 실제 사용자 연결 해제는 아직 미검증.
- 공개 웹 HTTP 200 및 Google/Apple 로그인 버튼 확인. 실제 소셜 로그인 왕복은 미검증.

## 남은 범위
- 토스 번들 업로드 후 휴대전화 테스트, 심사 요청, 승인/출시.
- 웹/토스 푸시 알림은 구현/출시되지 않음. iOS APNs 및 로컬 알림과 플랫폼 차이가 남음. 토스 기능성 알림은 템플릿 심사와 사용자 수신 동의가 필요함.
- iOS Live Activity는 웹/토스에 동일하게 제공되지 않음.
- 계정 삭제 RPC는 기존과 같이 계정/DB 기록을 삭제하지만 Storage의 잔여 프로필 사진 자동 정리는 별도 보완 필요. 사진 제거 기능 자체는 검증됨.
