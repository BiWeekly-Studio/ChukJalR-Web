# Matchday 디자인 전면 적용

## 변경 내용

- 홈, 대회 탐색, 예측 카드, 경기 상세·채팅, 랭킹, 내 기록, 토스 로그인·시작 안내에 네이비·라임 디자인을 적용했다.
- 원래 축잘알 워드로고의 글자·플레이트 형태와 단일 ‘축’ 앱 아이콘을 유지하고 공통 팔레트로 변경했다. 지원·약관 페이지에도 워드로고와 팔레트를 적용했다.
- 랭킹은 실제 전체 순위와 내 순위를 표시한다. 같은 전체 순위를 보여주던 미구현 리그별·친구 탭은 제거했다.
- 내 기록을 기록·응원/도전·설정으로 나누었다. 기존 구매, 구매 복원, 개인 도전, 알림, 프로필·계정 관리 기능을 유지했다.
- 홈의 ‘순서’에서 메이저·기타 그룹별 리그 순서를 편집할 수 있다. 서버 저장 성공 후 반영하고 현재 선택한 대회를 유지한다. 계정의 `profiles.league_order`만 갱신한다.
- 실제 사용자 데이터·서비스 연결은 기존 운영 Supabase를 사용한다. 이번 배포에서 서버 함수나 DB 마이그레이션을 추가 배포하지 않았다.
- iOS의 전체 화면 레이아웃 변경이나 App Store 업로드는 이번 작업 범위에 포함하지 않았다.

- 리그 이동·저장·새로고침 유지, 취소·기본 순서 복원, 예측 선택·확신도·완료 흐름을 격리된 미리보기에서 확인했다.

- 앱 정보 편집에서 라이트·다크 아이콘 모두 새 `public/brand/icon-600.png`로 선택했다. 상세 설명을 현재 8개 메이저 대회·국제대회, 리그 순서 편집, 기존 무료 예측과 선택 구매 설명으로 수정해 임시저장했다.
