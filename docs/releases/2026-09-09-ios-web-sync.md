# iOS / 웹 경기 기능 동기화

이번 국제대회 변경을 네이티브 Swift 앱에 반영했다. 토스 전용 결제 상품·광고 SDK를 iOS에 이식하는 작업은 포함하지 않는다.

- 기존 사용자의 리그 순서를 보존하고 새 대회를 이어서 표시한다.
- 리그·국제대회 메뉴와 챔스/유로파/컨퍼런스/A매치 바로가기.
- 경기 조회 범위 향후 60일, 팀·경기 500행 단위 페이지네이션.
- team_competitions를 읽어 챔스만 선택해도 출전 클럽을 응원팀으로 선택 가능.
- 컵 라운드 원문 보존. 국내 리그 순위를 국제대회 등수로 표시하지 않음.

검증:
- Xcode iPhone 17 Pro 시뮬레이터 BUILD SUCCEEDED.
- scripts/verify-ios-baselines.sh 통과.
- scripts/verify-ios-competitions.sh: 순서/복수 소속/토너먼트 라운드/1,562행 페이지네이션/중간 오류 전파 통과.
- 실제 운영 공개 데이터: 52개 대회 카탈로그, 965팀, 1,517경기 조회. 3개 UEFA 대항전/친선/네이션스리그 확인. 경기 양 팀 ID가 모두 팀 카탈로그에 존재.
- 시뮬레이터 287C4632-3C52-44E7-AACD-0982169E9937에 설치·실행. 기존 로그인 계정의 선호 순서 유지, 새 대회 탭 노출, 컨퍼런스 선택 시 10월 16일(KST) 실제 경기 표시를 UI에서 확인.

App Store Connect 업로드와 심사 제출은 하지 않았다. 이번 변경은 다음 iOS 배포에 포함해야 한다.
