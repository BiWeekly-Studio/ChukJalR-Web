# 축잘알 · 기존 워드로고의 Matchday 컬러

기존 ‘축잘알’ 워드로고의 형태를 유지한다. 세 글자의 획, ‘알’ 안의 축구공, 판의 비율, -4도 기울기와 외곽선은 기존 디자인을 따른다. 흰색·네이비·라임 팔레트로 새 화면과 맞춘다.

## 원본과 적용

- 웹: `src/components/Logo.tsx`의 Wordmark
- iOS: `ios/Sources/PlateLogo.swift`의 동일한 획과 판 좌표
- 색상: `design/system/tokens.json`
- 앱 아이콘: 기존처럼 첫 글자 ‘축’을 사용한다. 형태를 유지하고 색만 바꾼다.
- 일반적인 공 모양 UI 아이콘 BallMark는 로고와 별도다.

홈·로그인·로딩에는 기존 형태의 전체 워드로고를 쓴다. 이름 옆에 별도 신규 심볼을 붙이는 방식으로 대체하지 않는다.

## 파일

- `public/brand/wordmark-original.svg`: 기존 파랑·흰색·노랑 로고 비교본
- `public/brand/wordmark-light.svg`: 네이비 판, 흰색·라임 글자
- `public/brand/wordmark-dark.svg`: 네이비 판과 흰색·라임 글자, 밝은 외곽선
- 같은 이름의 PNG: 투명 배경, 1568px 너비
- `public/brand/icon-1024.png`, `icon-600.png`: ‘축’ 아이콘, 불투명 정사각형
- `/design/brand.html`: 기존 형태와 새 색상을 나란히 비교하는 페이지

실제 React 컴포넌트를 SVG로 렌더링하므로 다운로드 파일의 획과 웹 로고가 일치한다. 획이 만나는 지점은 하나의 경로로 칠해 확대 PNG의 가는 이음선을 방지한다.

```sh
npm run design:brand
```

PNG 출력에는 sharp가 필요하다. 로컬에 설치되어 있지 않으면 `BRAND_SHARP_PATH`에 설치된 sharp 모듈의 절대 경로를 지정한다. 일반 앱 빌드에서는 PNG 생성기를 실행하지 않는다.

## 사용 규칙

- 워드로고의 비율과 기울기를 임의로 바꾸지 않는다.
- 최소 너비 112px. 더 작은 정사각형 공간에는 기존 ‘축’ 아이콘을 쓴다.
- 주변 여백은 글자 높이의 1/4 이상 확보한다.
- 아이콘은 제출용 PNG에서 모서리를 미리 깎지 않는다. 플랫폼이 자체 마스크를 적용할 수 있다.
