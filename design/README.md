## 디자인 캔버스

`canvas/*.dc.html` 이 화면 소스이고, `canvas/canvas.json` 이 배치다.
네 개 아트보드 모두 모바일 390×844 기준이다.

공개본: https://claude.ai/code/artifact/737cc1a3-9f8e-4194-95af-1ae9fd84e07a

`canvas/chukjalal-prediction-game.html` 은 **생성물이라 git 에 넣지 않는다.**
캔버스 에디터가 통째로 들어 있어 2.5MB 이고, 재시드할 때마다 같은 크기의
블롭이 히스토리에 쌓인다. `dist/` 와 같은 취급이다. 필요하면 위 링크에서 열거나
`.dc.html` 로부터 다시 시드하면 된다.

## 고칠 때 주의

두 공개본 모두 **파일 경로에 묶여 있다.** 파일을 옮긴 뒤 그냥 다시 게시하면
같은 문서가 갱신되는 게 아니라 새 문서가 생긴다. 위의 URL 을 지정해서 게시해야 한다.
