## 설명 (4000자) — 821자

```
축잘알은 축구를 '읽는' 사람들의 리그입니다.

누구나 맞힐 수 있는 경기를 맞히는 건 실력이 아닙니다. 축잘알은 남들이 어떻게 봤는지와 비교해서 점수를 매깁니다. 모두가 홈 승을 고른 경기에서 홈이 이기면 얻는 게 적고, 아무도 보지 않은 결과를 읽어내면 크게 오릅니다.

■ 얼마나 확신하는지까지 겁니다
승·무·패를 고른 다음 확신도를 세 단계로 정합니다. 확신이 클수록 맞혔을 때 많이 얻고 틀렸을 때 많이 잃습니다. 그래서 '아무거나 세게 거는' 전략은 오래가지 않습니다.

■ 4대 리그, 매일 새 경기
프리미어리그 · 라리가 · 분데스리가 · 세리에A 의 일정과 결과를 매일 받아옵니다. 좋아하는 리그를 고른 순서대로 홈 화면이 정렬되고, 최애 팀 경기는 맨 위에 모입니다.

■ 경기를 같이 봅니다
킥오프 한 시간 전에 경기 채팅이 열립니다. 실시간 스코어와 득점·경고 기록이 함께 올라오고, 앱을 닫아도 잠금화면에서 점수를 볼 수 있습니다.

■ 내가 어디에 강한지 알려드립니다
리그별 적중률, 확신도가 실제로 정확한지, 홈·무승부·원정 중 어디에 잘 거는지, 그리고 최애 팀 경기에서 팬심이 판단을 흐리는지까지 보여드립니다. 지수가 어떻게 움직여 왔는지도 한눈에 봅니다.

■ 순위는 매일 아침 확정됩니다
정산된 예측 20경기를 채우면 순위표에 이름이 올라갑니다. 배치를 두는 이유는 단순합니다 — 운으로 세 번 맞힌 사람이 1위가 되면 순위표가 의미를 잃기 때문입니다.

축잘알에는 현금 베팅이 없습니다. 돈을 걸 수 없고, 상금도 없고, 인앱 결제도 없습니다. 앱 안의 포인트는 현금으로 바꿀 수 없습니다. 겨루는 것은 오직 축구를 읽는 눈입니다.
```

> 마지막 문단은 심사를 위한 것이기도 하다. 예측·순위·포인트가 나오는 앱은
> 도박으로 오해받기 쉬워서, 설명 안에 아니라는 근거를 남겨둔다.

## 지원 URL (필수)

```
https://<배포도메인>/support.html
```

페이지는 `public/support.html` 에 만들어 뒀다 — 문의 메일, 점수 규칙, 예측 마감,
순위 조건, 채팅 시간, 닉네임 변경, 계정 삭제, 신고·차단, 그리고 "현금 베팅 없음"까지
심사자가 확인할 것들이 다 들어 있다.

**아직 웹이 배포돼 있지 않다.** 이 URL 이 열리지 않으면 제출이 막히므로 먼저 올려야
한다. 가장 빠른 길:

```
npm run build
npx vercel deploy --prod dist
```

Vercel 무료 플랜이면 `chukjalal.vercel.app` 같은 주소가 바로 나온다. 나중에 도메인을
사면 그때 바꿔도 되고, 심사 중에 바꿔도 문제되지 않는다.

## 개인정보 처리방침 URL (필수)

```
https://<배포도메인>/privacy.html
```

페이지는 `public/privacy.html` 에 있다. 지원 URL 과 같은 배포에 함께 올라간다.
**이 URL 이 실제로 열려야 제출이 통과된다.**

## 마케팅 URL (선택)

**비워둔다.** 홍보용 랜딩 페이지가 실제로 있을 때만 넣는 자리다. 지원 URL 과 같은
주소를 넣거나 빈 페이지를 가리키면 심사자가 열어보고 지적한다. 나중에 소개
페이지를 만들면 그때 채우면 된다.

## 저작권

```
2026 JalR Company
```

> 형식은 `연도 + 권리자` 이고 © 기호는 넣지 않는다 (App Store 가 붙여준다).
> **여기 적는 이름은 App Store Connect 계정의 법인·개인 이름과 같아야 한다.**
> 개발자 계정이 다른 이름(예: BiWeekly Studio)으로 돼 있으면 그 이름을 쓴다 —
> 다르면 심사에서 권리 관계를 묻는다.

## App Privacy (개인정보 보호 정보)

수집하는 데이터를 아래처럼 선택한다. **추적(Tracking)은 전부 '아니오'.**

| 데이터 | 수집 | 계정 연결 | 추적 | 용도 |
|---|---|---|---|---|
| 이메일 주소 | 예 | 예 | 아니오 | 앱 기능 |
| 사용자 ID | 예 | 예 | 아니오 | 앱 기능 |
| 사진 | 예 | 예 | 아니오 | 앱 기능 (프로필 사진, 올린 경우만) |
| 기타 사용자 콘텐츠 | 예 | 예 | 아니오 | 앱 기능 (채팅 메시지) |

수집하지 않음: 위치, 연락처, 검색 기록, 구매 내역, 진단, 광고 식별자, 사용 데이터.

> 앱 번들의 `PrivacyInfo.xcprivacy` 와 위 표는 서로 어긋나면 안 된다. 하나를 고치면
> 다른 하나도 같이 고칠 것.

## 심사 메모 (App Review Information)

```
축잘알은 축구 경기 결과를 예측하고 순위를 겨루는 앱입니다.
현금 베팅, 상금, 인앱 결제가 전혀 없습니다. 앱 안의 '포인트'는 현금으로 바꿀 수 없고
레벨 진행에만 쓰입니다.

[로그인]
Apple로 로그인 또는 Google로 로그인만 지원합니다. 심사자님의 Apple 계정으로
바로 로그인하실 수 있으며, 별도의 데모 계정은 필요하지 않습니다.
로그인 후 리그 선택 → 최애 팀 선택(건너뛰기 가능) 순으로 진행됩니다.

[계정 삭제]
'나' 탭 맨 아래 '계정 삭제'에서 앱 안에서 바로 삭제할 수 있습니다.

[사용자 생성 콘텐츠]
경기 채팅이 있습니다. 킥오프 1시간 전부터 종료 4시간 후까지 열립니다.
- 메시지 신고: 상대 메시지의 '…' 버튼
- 사용자 차단: 같은 메뉴의 '이 사람 차단'
- 자동 필터: 링크와 금칙어를 서버에서 차단하고, 신고 3건이 쌓이면 자동으로 가려집니다.
심사 시점에 진행 중인 경기가 없으면 채팅이 닫혀 있을 수 있습니다.
그때는 경기 상세 화면에서 '채팅은 킥오프 1시간 전에 열려요' 안내가 표시됩니다.

[Live Activity]
경기 채팅방에 들어가면 잠금화면에 실시간 스코어가 표시됩니다.

[데이터 출처]
경기 일정과 결과는 API-Football 에서 받아옵니다.
```
